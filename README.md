# Developer Portfolio

My personal portfolio website, built with plain HTML, CSS and JavaScript.

**Live site:** https://tvisha-cmd.github.io/Datheon_Full_Stack_Web_Development_Internship/

## Features
- Responsive layout that works on phones and computers (Flexbox and CSS Grid)
- Dark and light theme toggle that remembers your choice
- Smooth scrolling navigation with a hamburger menu on small screens
- Project cards that open in a popup with more details
- Sections: Hero, About, Skills, Projects, Contact

## Run locally
Download the files and open `index.html` in your browser. No installation needed.

## Project structure
- `index.html`: page content and structure
- `style.css`: design and responsive layout
- `script.js`: theme toggle, mobile menu and project popups

## Deployment
Hosted on GitHub Pages from the `main` branch.

HTML5, CSS3, JavaScript (ES6+)
